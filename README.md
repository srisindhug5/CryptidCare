# CryptidCare

## Overview
CryptidCare is a .NET-based API designed to process prescription claims for mythical beings (e.g., Werewolves, Hydras, Phoenixes).

## Tech Stack
- .NET 10
- ASP.NET Core Web API
- SQL Server (Docker)
- Entity Framework Core

## Project Structure
- CryptidCare.Api → API layer
- CryptidCare.Application → Business logic
- CryptidCare.Domain → Core entities
- CryptidCare.Data → Data access
- CryptidCare.Tests → Unit tests

## Features
- Claims processing engine
- Clean architecture implementation
- Scalable and extensible design

## Getting Started
1. Clone repo
2. Run `dotnet build`
3. Run API using Visual Studio or `dotnet run`
